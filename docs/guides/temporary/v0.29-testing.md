# Billing Approvals and Patient Bills — Testing Guide

A short script to test version 0.29: discounts, waivers and pay-later asked for at the Cashier and decided by a manager, and the Patient Bills board. Each test says what to do and what the system should do. Tick each one off. If anything behaves differently, send a screenshot.

Test on the demo hospital (hospital.royceltd.com). How it works day to day: [Reception, queue and billing](../12-reception-queue-billing.md), Steps 9a and 9b.

## Before you start

| Login | Roles | Used for |
| --- | --- | --- |
| Cashier | Cashier | Bills, requests |
| Manager | Healthcare Administrator | Deciding requests |
| A second manager | Accounts Manager | Deciding the first manager's own request |

## A. Discount

1. **Cashier:** check in a cash patient with a consultation and a lab test. On the visit, **Bill › Create Bill** and save the bill as a draft (don't submit it).
2. **Bill › Request Discount**: 10%, reason "Staff relative".
   - [ ] "BAR-… sent to a manager for approval". The visit's Bill section lists it under **Approvals**, *Pending*.
   - [ ] The cashier sees no Approve button on the request.
3. **Manager:** Kenya Health › Patients › **Patient Bills** › **Approvals waiting** › open the request › **Approve**.
   - [ ] *Approved*. The draft bill's total is 10% lower, with a comment naming the manager.
   - [ ] The visit's **To pay** is the discounted total.
4. Submit the bill first, then try **Request Discount** on it.
   - [ ] Refused: ask for a waiver instead.

## B. Waiver

1. **Cashier:** submit a bill without taking payment. **Bill › Request Waiver**, leave the amount blank, reason "Can't pay".
   - [ ] The amount is the bill's whole balance. A larger amount is refused.
2. **Manager:** approve it.
   - [ ] The bill's balance is 0. A Journal Entry (Write Off Entry) is linked on the request.
   - [ ] On Patient Bills the amount shows under *Discount / waived* and the balance is 0.

## C. Pay later

1. **Cashier:** on a cash visit, **Bill › Request Pay Later**.
2. **Manager:** approve.
   - [ ] The visit is served before payment (the lab can collect samples unpaid).

## D. Controls

1. **Manager:** ask for a pay-later yourself, then try to approve it.
   - [ ] Refused: "You can't decide your own request". The second manager can.
2. **Reject** a request without a reason.
   - [ ] A reason is required.

## E. Patient Bills

1. Open **Patient Bills** for the last 7 days.
   - [ ] One row per visit, totals at the bottom; insured visits only on the **Insurance bills** tab, with the payer and the insurance column.
   - [ ] *Has balance* shows only visits that still owe or have bills to make; *Cleared* the rest.
   - [ ] **Approvals waiting** shows the number of requests waiting, and opens them.
