# Surveillance, Child Growth, Clinical Alerts and Quality Measures — Testing Guide

A script to test versions 0.30 to 0.33:
- disease surveillance (IDSR);
- child growth and therapy services;
- clinical alerts;
- quality measures;
- quarterly and annual MOH reports.

Each test says what to do and what the system should do. Tick each one off. If anything behaves differently, send a screenshot.

Test on the demo hospital (**hospital.royceltd.com**). How each feature works day to day: [Guide 17](../17-surveillance-growth-alerts-quality.md).

### Setup, once (Royce prepares the demo)

Royce does this before testing starts:
- The demo gets these diagnoses, each with its ICD-10 and ICD-11 code:

  | Diagnosis | ICD-10 | ICD-11 |
  | --- | --- | --- |
  | Cholera, suspected | A00.9 | 1A00 |
  | Measles | B05.9 | 1F03 |
  | Typhoid fever | A01.0 | 1A07 |
  | Essential hypertension | I10 | BA00 |
  | Type 2 diabetes mellitus | E11.9 | 5A11 |

- The roles *Healthcare Administrator*, *Physician* and *Nursing User* get **Read** and **Select** on *Company*, which the reports' company filter needs. An administrator can do this themselves: **Role Permissions Manager** › Document Type *Company* › add a rule for each role.

Then check:
1. - [ ] The manager opens Kenya Health › Reports › **Quality Measures** without a permission message.
2. - [ ] The five diagnoses above can be chosen on a consultation.
3. Check Kenya Health Settings:
   - [ ] **Clinical Alerts** is ticked.
   - [ ] Therapy Types *Physiotherapy*, *Occupational Therapy*, *Counselling* and *Medical Social Work* exist. If not, click **Add Therapy and Counselling Services**.
   - [ ] The WHO growth standards are loaded. If the growth chart says they aren't, click **Load WHO Growth Standards**.

Use new test patients with "Test" in the name, so they're easy to find and clean up.

## A. Immediately reportable disease

1. **Doctor:** consult a test adult and add the diagnosis *Cholera, suspected*. **Submit** the consultation.
   - [ ] Submitting works as usual: nothing blocks the doctor.
2. **Manager:** open the notification bell.
   - [ ] An alert: "Immediately reportable: suspected Cholera (NDC-…) … Notify the county within 24 hours", and that cholera is IHR notifiable.
   - [ ] The alert does not name the patient.
3. Open the case from the alert (or Kenya Health › Disease Surveillance › **Notifiable Disease Case**).
   - [ ] The disease, *Immediately Reportable*, IHR ticked, status *New*, the patient, their age, sex and county, the consultation and the diagnosis.
4. Set **Status** to *Notified to County*, fill in *Notified to County On* and a reference, set **Outcome** to *Alive* and save.
   - [ ] Saved.

## B. No double counting

1. **Doctor:** consult the same patient again today, again with *Cholera, suspected*, and submit.
   - [ ] No second case for this patient, and no second alert.
2. Do the same with *Measles* for another test patient.
   - [ ] A new measles case and a new alert.

## C. Outbreak alert

1. **Manager:** Disease Surveillance › **Notifiable Disease** › *Typhoid Fever*. Note its threshold (5 cases in 7 days), set **Outbreak Alert at** to **2** and save.
2. **Doctor:** submit consultations for two different test patients with *Typhoid fever*.
   - [ ] After the first: no alert. Typhoid is weekly reportable and below the threshold.
   - [ ] After the second: the manager gets "Outbreak alert: 2 cases of Typhoid Fever…". **Public Health Event** has one *Outbreak Alert*, source *Automatic Threshold*, cases 2.
3. Submit a third typhoid consultation.
   - [ ] No new alert. The same event now shows 3 cases.
4. **Manager:** set the typhoid threshold back to **5**.

## D. Rumour reported by staff

1. **Nurse:** Disease Surveillance › **Public Health Event** › *+ Add*. Event Type *Rumour*, Source *Community*, a description, a place and the number of people. Save.
   - [ ] Saved.
   - [ ] The manager gets "Public health event reported: Rumour…".
2. **Manager:** set the status to *Verified*, fill in *Verified By* and *Action Taken*, and save.

## E. IDSR weekly report

1. **Manager:** Disease Surveillance › **IDSR Weekly Report**, this year and this week's number.
   - [ ] The heading gives the week's dates, Monday to Sunday.
   - [ ] All 27 diseases are listed, most with 0 (zero reporting).
   - [ ] Cholera, measles and typhoid show the cases from tests A to C, split under 5 and 5+. The total row adds them up.
2. Open the cholera case from test A, set **Outcome** to *Died*, save, and refresh the report.
   - [ ] Cholera shows 1 death.
   - [ ] Set it back to *Alive*.

## F. Quarterly and annual MOH reports

1. Open **MOH 705 Outpatient Summary**, set **Period** to *Quarter* and choose Q4.
   - [ ] One column per month (Oct, Nov, Dec) and a total.
2. Set Period to *Month*, November.
   - [ ] The November column in the quarter view equals the monthly total for each row.
3. Run **MOH 706**, **711** and **717** with Period *Year*.
   - [ ] Each one runs.

## G. Child growth

1. **Reception:** register a test child, aged about 1 year (girl or boy).
2. **Nurse:** Vital Signs for the child: weight **6.5** kg, height **0.75** (metres). Save.
   - [ ] A **Child Growth (WHO)** section shows the z-scores and a **Nutrition Status** of *Severe wasting (SAM)…*.
3. Add another Vital Signs for the same child with a healthy weight, about 9.5 kg at 0.75 m.
   - [ ] Nutrition status *Normal growth*.
4. **Doctor:** open the child › **View** › **Growth Chart**.
   - [ ] The WHO lines (green median, orange -2/+2, red -3/+3), the child's dots, and a table of dates, values and z-scores.
   - [ ] Switching to *Length/height-for-age* works.
5. Record vital signs for a test adult.
   - [ ] No growth section, and no Growth Chart button on an adult.

## H. Therapy, counselling and social work

1. **Doctor:** in a consultation, on the **Therapies** table add *Counselling* (2 sessions) and *Occupational Therapy* (1 session). Submit.
   - [ ] A Therapy Plan for the patient with both services.
2. Open a **Therapy Session** for the plan (Counselling), write **Session Notes** and save.
   - [ ] The notes are kept on the session.
3. On the patient, add a **Clinical Note** of type *Social Work Assessment*.
   - [ ] The types *Social Work Assessment*, *Counselling Session*, *Occupational Therapy Note* and *Physiotherapy Note* are available.
4. **Manager:** open the Therapy Type *Counselling*.
   - [ ] *Is Billable* is not ticked: nothing is billed until a price is set.

## I. Clinical alerts

1. **Fever in a child.** **Nurse:** vital signs for a test child aged 2 or 3, temperature **38.5**, SpO2 **88**. **Doctor:** start the consultation and **Save** it.
   - [ ] A red banner: "3 clinical alert(s) to review (1 critical)".
   - [ ] **Review** lists *Low oxygen saturation* (Critical), *Fever in a child under 5* (Warning) and *Check immunisation status* (Info), each with its guideline.
2. Click **Acted On** for the fever alert. Click **Override** for the low oxygen alert, try to confirm without a reason, then give a reason.
   - [ ] Overriding needs a reason. Each answered alert leaves the list, and the banner count goes down.
   - [ ] The consultation can be submitted with alerts still unanswered.
3. **Penicillin allergy.** Register a test adult with Allergies "Penicillin". **Doctor:** prescribe *Capsule Amoxicillin 500mg* and save.
   - [ ] Critical alert: *Penicillin allergy: penicillin prescribed*.
4. **Problem list.** **Doctor:** a test adult with *Type 2 diabetes mellitus*. Submit. Next, open a new consultation for the same patient with no diagnosis and save it.
   - [ ] The second consultation shows *Diabetes: routine care*, from the earlier diagnosis.
5. **Recalled medicine.** **Manager:** open the Medication *Tablet Paracetamol 500mg* › *Safety Alerts* › tick **Recalled**, write a recall notice, and add *Side Effects to Explain*: "Nausea". **Doctor:** prescribe it and save.
   - [ ] Critical alert that it is recalled, with the notice, and an info alert with the side effects.
   - [ ] **Manager:** untick *Recalled* and clear the side effects afterwards.
6. **Switching off.** **Manager:** untick Kenya Health Settings › **Clinical Alerts**. **Doctor:** repeat step 1 with a new child.
   - [ ] No alerts.
   - [ ] **Manager:** tick Clinical Alerts again.
7. **Manager:** Reports › **Clinical Alert Summary**, today, *Per Clinician*, then *Per Alert*.
   - [ ] The alerts from this section, with acted on, overridden and not answered counts and the response rate.
8. **Manager:** Setup › **Clinical Alert Rule** › *Fever in a child under 5*: untick **Enabled**. Repeat step 1 with a new child.
   - [ ] No fever alert; the other alerts still show.
   - [ ] Tick **Enabled** again.

## J. Quality measures

1. **Manager:** Reports › **Quality Measures**, from the 1st of this month to today.
   - [ ] 9 measures with numerator, denominator, rate, target and *Met* (green Yes or red No).
   - [ ] *Children under 5 weighed* counts the child consultations from G and I. *Clinical alerts answered* counts the alerts from I.
2. Click **Save Results**, then click it again.
   - [ ] "… results saved". **Quality Measure Result** has one result per measure for the period, not two.
3. **Export › FHIR MeasureReport (JSON)**, then **Export › CSV**.
   - [ ] Two files download. The JSON starts with `"resourceType": "Bundle"`, and the CSV opens in Excel with one row per measure.
4. In the CSV, keep the header and the *QM-CLIENT-SAT* row. Change the dates to last month and the numerator and denominator to 42 and 50. **Import Results** with that file.
   - [ ] "1 results imported". Run the report for last month: *Clients satisfied* shows 84%, source *Imported*, *Met* No (target 85%).
5. Import a CSV with a measure code that doesn't exist.
   - [ ] It is listed as unknown, and nothing is created.

## After testing
