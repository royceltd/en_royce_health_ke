# Registration, Check-in and Triage Changes — Testing Guide

A script to test version 0.34, the first changes from your outpatient flow feedback of 16 November:
- one contact number on registration;
- sub-counties offered once the county is chosen;
- success messages that close by themselves;
- the insurance member number typed at check-in, not chosen from a list;
- height in centimetres at triage;
- symptoms, appointment type and source taken off the consultation.

Each test says what to do and what the system should do. Tick each one off. If anything behaves differently, send a screenshot.

Test on your own system (**bethesda.royceltd.com**) with your staff logins. The same changes are on the demo hospital (hospital.royceltd.com).

Still to come from the same feedback, in the next versions: the consultation fee paid before triage, requests hidden at service points until paid, the billing desk (tick the requested services, invoice, receipt), the consultation in separate tabs, the pharmacist substitution lock, and nursing requests.

## Before you start

| Login | Used for |
| --- | --- |
| Reception | Registering patients, check-in |
| Nurse | Vital signs at triage |
| Doctor | Consultations |

Use new test patients with "Test" in the name, so they're easy to find and clean up.

## A. Registration

1. **Reception:** open **Patient** › **+ Add Patient** (the full form).
   - [ ] There is one contact number field, **Mobile**. The separate **Phone** field is gone.
2. Choose **County of Residence** *Nakuru*. Click in **Sub-County**.
   - [ ] Nakuru's sub-counties are listed (Molo, Njoro, Naivasha, Gilgil, …). Typing filters the list.
   - [ ] Choose one. It fills the field.
3. Change the county to *Nairobi*.
   - [ ] The Nakuru sub-county is cleared, and Nairobi's are offered (Westlands, Kasarani, …).
4. Type a sub-county that is not on the list.
   - [ ] It is kept. The list helps but never blocks.
5. Fill in the rest and **Save**.
   - [ ] Saved, with the mobile number and sub-county.

Patients registered earlier with only a Phone number now show it under Mobile.

## B. Messages that close by themselves

1. Do something that ends in a green "done" message. For example, **Pharmacist:** in the **Pharmacy Worklist**, open a cash patient's prescription and click **Bill Drugs**.
   - [ ] The green "Billed" message closes by itself after about 5 seconds.
2. Do something that shows a warning or an error, for example save a patient without a required detail.
   - [ ] The message stays until you close it.

Messages that ask a question (with buttons to choose) never close by themselves.

## C. Insurance member number at check-in

1. **Reception:** check a test patient in (**Check In (New Visit)** on the patient), **Payment** *Insurance*.
   - [ ] There is no **Insurance Policy** list to choose from. You choose the **Payer** and type the **Member / Policy No.** and **Cover Valid Until**.
2. Fill in payer, member number and a date a year ahead. **Save**.
   - [ ] The visit saves. The patient's policy was created from what you typed.
3. Complete that visit (or use the next day) and check the same patient in again as *Insurance* with the same payer.
   - [ ] Member number and cover date fill in by themselves from the last visit. You can change them.
4. Type a later **Cover Valid Until** (the member's card was renewed) and save.
   - [ ] Saved; the patient's policy now runs to the new date.
5. Type a **Cover Valid Until** in the past.
   - [ ] Refused: "The cover expired on …".

## D. Height in centimetres

1. **Nurse:** record **Vital Signs** for a test adult: weight *72*, **Height (cm)** *170*.
   - [ ] There is one height field, in centimetres.
   - [ ] BMI fills in by itself: *24.91*, *Normal*.
2. Type *1.7* in **Height (cm)**.
   - [ ] A message says height is in centimetres. Saving with 1.7 is refused.
3. Save with 170.
   - [ ] The Vital Signs list shows the height as 170.
   - [ ] On a printed consultation summary, height shows as "170 cm".

Heights recorded earlier in metres now show in centimetres too.

## E. Consultation

1. **Doctor:** open a consultation for a checked-in test patient (from the visit: **Record** › **Consultation**).
   - [ ] **Symptoms**, **Appointment Type** and **Source** are no longer on the form.
2. Fill in the diagnosis and save.
   - [ ] Saved without asking for an appointment type. The consultation fee is billed as before.

The hospital can show any of these fields again (**Customize Form**); an update never hides them again.
