# Security Basics: Logins, Users, Screen Lock and the Compliance Check — Testing Guide

A short script for version 0.43, the first of the security and privacy safeguards that DHA certification and the Data Protection Commissioner (ODPC) look for.

Test on the demo (**hospital.royceltd.com**) or your own system. Use a test user, not a real staff member. Each test says what to do and what the system should do; tick it off, and send a screenshot if anything differs.

## A. The Compliance Check (manager or administrator)

1. Kenya Health › Setup › **Compliance Check**.
   - [ ] Every row is *Pass*, except **Two-factor authentication**, which shows *Advice* (recommended for managers, not required).
2. Setup › System Settings: set **Allow Consecutive Login Attempts** to 20, save, and refresh the Compliance Check.
   - [ ] *Account locked after failed logins* shows **Fail**. Set it back to 5.

## B. Locked after failed logins

1. In a private browser window, log in as the test user with a wrong password five times.
   - [ ] The account is locked; even the right password is refused for about 10 minutes.

## C. Screen lock when idle

1. **Manager:** Kenya Health Settings › **Idle Screen Lock (minutes)** = 1 (for the test).
2. As the test user, open a new Consultation (or any form), type something, and don't touch the mouse or keyboard for a minute or two.
   - [ ] The screen blurs and asks for the password.
3. Type a wrong password.
   - [ ] "Wrong password (1 of 5)". (Five wrong passwords log the user out.)
4. Type the right password.
   - [ ] The screen unlocks and what you typed is still there.
5. **Manager:** set it back to 10.

## D. Users expire, and are disabled, not deleted

1. **Manager:** on the test user, set **Valid Until** to yesterday and save.
   - [ ] The next morning (the daily job), the account is disabled, with a note saying why. Ticking **Enabled** again is refused until **Valid Until** is moved to a later date.
2. Try to **Delete** a user who has worked in the system (created or changed any record).
   - [ ] Refused: "Disable, don't delete". A brand-new user who never worked can still be deleted.

## E. Audit trail

1. Open a consultation or lab test that has been edited, then **…› View Versions** (or the activity at the bottom).
   - [ ] Each change shows the old and new value, who, and when.
2. **Manager:** Kenya Health › Patient Record Access.
   - [ ] Each opening and printing of a patient's record is listed, with the user and the IP address.
