# Version 0.60: Diagnosis Search and the Sidebar — Testing Guide

This testing script covers version 0.60.0, your feedback of 23 November:

- **Diagnosis:**
  - choose a diagnosis by its name and the ICD-11 code fills in;
  - start with the code and the name fills in;
  - this now works whether you pick from the list or just type, in either column.
- **The sidebar:** only one section stays open at a time, so the menu no longer grows into a long list.

Test on the demo, **hospital.royceltd.com**. Press **Ctrl+Shift+R** first, so your browser loads the new version. Tick each item as you go, and send a screenshot if anything is different.

Your own system's diagnoses now all have their ICD-11 code. Before 22 November they had none, which is why choosing one by name filled no code.

## A. Diagnosis on the consultation (Doctor)

On an open consultation, go to the **Diagnosis** tab and add a row for each test below.

1. In the **Diagnosis** column, type *malaria* and pick *Malaria, unspecified* from the list.
   - [ ] The **ICD-11 Code** column fills with *1F4Z*.
2. On a new row, type *1F4Z* in the **ICD-11 Code** column and pick it.
   - [ ] The **Diagnosis** column fills with the name.
3. On a new row, type the code *1F4Z* in the **Diagnosis** column and press Tab, without picking from the list.
   - [ ] The name and the code both fill in.
4. On a new row, type a diagnosis in small letters, for example *malaria, unspecified*, and press Tab without picking.
   - [ ] It is matched, and the code fills in.
5. On a new row, type something that is not a full name, for example *Malar*, and press Tab without picking.
   - [ ] A message says it is not a diagnosis or an ICD-11 title, with a few choices.
   - [ ] The cell is emptied, so nothing wrong is saved.

## B. Diagnosis on the ward (Doctor)

On an admitted patient's screen, open **Diagnosis**.

1. Choose a diagnosis by name.
   - [ ] The ICD-11 Code fills in. Press **Add Diagnosis**: it is added with its code.
2. Type a code (for example *1F4Z*) in **ICD-11 Code**.
   - [ ] The diagnosis name fills in.
3. Type *Malar* in **Diagnosis** and leave the field.
   - [ ] The same message with choices shows, and the field is emptied.

## C. The sidebar (anyone)

1. In the sidebar, open one section (for example **Consultation**), then open another (for example **Inpatient**).
   - [ ] The first section closes when the second opens.
2. Open a page from a section, then go to a page in a different section (for example from **Ward** to **Lab Worklist**).
   - [ ] Only the section of the page you are on is open.
3. Reload the page (Ctrl+Shift+R).
   - [ ] Only the current page's section is open.
