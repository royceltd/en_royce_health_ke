# The Lab Pack: Full Haemogram, One Report per Visit, Faster Results Entry, Walk-ins at Reception — Testing Guide

This is a short testing script for version 0.49.0. It covers what Bethesda's laboratory technician asked for in the demo of 19 November:

- the **Full Haemogram**, set up as the Mindray BC-20s prints it;
- on the **Completed** tab, one menu per visit to view, print, download, email and print the request;
- **Enter** moving to the next result while typing results;
- walk-in lab patients registered at **reception**.

Test on the demo, **hospital.royceltd.com**, or on your local server. Use the Lab, Reception and Cashier logins, and the Administrator for part A. Tick each item as you go, and send a screenshot if anything is different.

## A. Full Haemogram (Administrator or lab manager)

1. Kenya Health › Laboratory › **Lab Worklist** › the **⋯** menu › **Standard Tests**.
   - [ ] *Full Haemogram* is listed, with the note *Mindray BC-20s 3-part differential* and *19 parameters*.
2. Choose *Full Haemogram*, cash price *1,200*, leave the item code blank, **Add Test**.
   - [ ] The new test opens. Its type is *Compound* and its rows are, in this order: WBC, Lymph#, Mid#, Gran#, Lymph%, Mid%, Gran%, RBC, HGB, HCT, MCV, MCH, MCHC, RDW-CV, RDW-SD, PLT, MPV, PDW, PCT.
   - [ ] Each row has the analyser's unit and range, for example HGB *g/dL*, *12.0 - 16.0*; PLT *10^9/L*, *150 - 450*.
3. Open **Standard Tests** again.
   - [ ] *Full Haemogram* shows *Set up* and cannot be added twice.
4. Change one range on the test (for example a range for men and women: *F 12.0 - 15.5 / M 13.5 - 17.5*) and save.
   - [ ] The next haemogram uses the new range.

## B. Typing results with Enter (Lab)

1. Order a Full Haemogram for a patient (doctor's request or walk-in), take payment, then on the **Requests** tab **Collect Samples**.
2. **Results Entry** tab › open the patient › **Enter Results**.
   - [ ] The 19 parameters are listed in the analyser's order, with unit and normal range.
3. Click in WBC, type *12.5* and press **Enter**.
   - [ ] The cursor moves to Lymph#. WBC shows a red **H**.
4. Keep typing and pressing **Enter** down to PCT, then press **Enter** once more.
   - [ ] Nothing is saved and the box stays open. Saving is only by **Save** or **Save and Validate**.
5. **Save and Validate** and confirm.

## C. The Completed tab (Lab)

1. Order and validate a second test on the same visit (for example Malaria Blood Slide).
2. **Completed** tab.
   - [ ] The visit has one row with an **Actions** button.
3. **Actions › View**.
   - [ ] One Laboratory Report opens with both tests, each with its own results and *Verified by*. The visit number is in the header.
4. **Actions › Print**.
   - [ ] The same report opens with the print box.
5. **Actions › Download PDF**.
   - [ ] A PDF of the same report is downloaded.
6. **Actions › Print Request**.
   - [ ] The Laboratory Request prints: requesting clinician, the diagnosis from the consultation, each test with specimen, urgency, when requested and when collected, and who collected the samples.
7. **Actions › Send to Patient**.
   - [ ] The patient's email is filled in when the record has one. Send it.
   - [ ] The patient receives the report as a PDF.
   - [ ] Patient › **View › Who Opened This Record** lists the tests with the action *Email* and the address.
   - [ ] If no outgoing email account is set up, a message says so instead.
8. Click the row itself (not the Actions button).
   - [ ] The tests of the order open as before.

There is no Word copy: validated results cannot be edited.

## D. Walk-in at reception (Reception, Cashier, Lab)

1. **Reception:** find or register the patient › **Create › Lab Walk-in (Tests Only)**.
   - [ ] The test list shows each test's cash price.
2. Choose *Full Haemogram*, *Referred by*: *Dr Outside, Town Clinic*, **Create Requests**.
   - [ ] The *Lab only* visit opens. The message says cash patients pay at the Cashier first.
3. **Lab:** Lab Worklist › **Requests**.
   - [ ] The patient is not listed yet; the note under the list counts patients paying at the Cashier.
4. **Cashier:** take payment for the visit.
5. **Lab:** **Refresh**.
   - [ ] The patient is on the Requests tab, ready to collect.
6. **Cashier** login: open a patient.
   - [ ] There is no *Lab Walk-in* button.
